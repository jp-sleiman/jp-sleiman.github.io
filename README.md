# Jean-Pierre Sleiman

Personal academic website, prepared for GitHub Pages under a personal account.

## Publish

Place the contents of this folder at the root of your personal website repository. In Settings → Pages, select Deploy from a branch, main, and /(root).

## Update

Edit index.html for your bio, publication text, and links. Add or replace media in assets/. The filenames used for animated previews are also referenced in assets/site.js. Commit changes to publish updates.

## Take offline

In Settings → Pages, choose Unpublish site. To prevent another deployment, disable the publishing source by choosing None.
